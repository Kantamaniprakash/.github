# .github

This repository holds **account-wide default community health files** for
[@Kantamaniprakash](https://github.com/Kantamaniprakash).

GitHub automatically applies these defaults to any of my repositories that don't
provide their own copy:

- [`SECURITY.md`](SECURITY.md) — how to report a vulnerability
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to set up and contribute
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — community expectations
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) — bug & feature issue forms
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) — PR checklist

See GitHub's docs on
[default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
